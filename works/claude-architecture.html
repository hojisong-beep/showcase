③ 소스 이동 & 동기화 명령

💻 로컬 → GitHub

git add -A
git commit -m "메시지"
git push -u origin my-branch
gh pr create --fill
  • Claude Code에게 “커밋하고 PR 만들어줘”라고 하면 위 명령을 대신 실행

🐙 GitHub → 로컬

git clone <repo-url>
git fetch origin
git checkout claude/xxxx   # 웹 세션이 만든 브랜치
git pull

🔁 로컬 ⇄ 웹 Claude Code 세션

claude --remote "작업 내용"   # 로컬에서 시작→클라우드 VM이 수행
claude --teleport <session-id>  # 웹 세션을 내 터미널로 가져오기
/teleport                      # (세션 안에서) 같은 기능
  • 웹은 GitHub에 push된 것만 보임 → 로컬 미커밋 변경은 먼저 push
  • 웹 작업 결과는 항상 브랜치/PR로 돌아옴 → 로컬에서 fetch/checkout
  • ※ 플래그 이름은 버전에 따라 다를 수 있음 (claude --help 확인)

④ VS Code: 터미널 vs 확장(플러그인) vs CLI

⌨️ 터미널에서 claude (= CLI)

  • 텍스트 UI(TUI), 키보드 중심, 모든 슬래시 명령
  • VS Code 밖(iTerm, SSH, CI)에서도 동일하게 사용
  • claude -p "…" 비대화 모드 → 스크립트·CI·Agent SDK
  • /ide로 에디터와 연결하면 선택 영역·diff 공유

🧩 VS Code 확장 (Claude Code 패널)

  • 사이드 패널 GUI, 에디터 내 인라인 diff 승인
  • 선택 코드 자동 컨텍스트, @파일 멘션, 체크포인트 되돌리기
  • VS Code 안에서만 사용 (UI 래퍼)
공통점: 둘 다 내 PC(또는 Remote 서버)에서 같은 엔진으로 실행 · 같은 계정 인증 · 같은 CLAUDE.md, ~/.claude/settings.json, MCP, hooks, skills 공유 → 코드는 내 디스크에 있고, 프롬프트/컨텍스트만 Anthropic API로 전송됩니다.
